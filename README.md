# Bonsai UI

Accessible here: https://ay-bonsai-ui.streamlit.app/

Run with:

```bash
streamlit run streamlit_app.py
```

Notes:

- Only Python 3.13 installation has Streamlit.
- Also requires installing `streamlit-echarts`.

Conda environment:

```bash
conda env list
conda activate py313
```

Dependency refresh:

```bash
pip-compile --upgrade requirements.in
```
